# 钢材产业基本面量化系统

当前阶段：A｜框架版本：A-scaffold-0.1｜建立日期：2026-09-19

本项目以螺纹钢为交易研究对象，覆盖钢材产业资源、卷螺分配、现货、情绪、价格与宏观。当前交付是研究框架和填写模板，正式模型尚未建立。外部工具已完成只读查询验证，但项目还没有真实数据集或自动采集流程。

## 从这里开始

1. 阅读 [A01 策略总纲](阶段A/A01_策略总纲.md)，了解边界与原则。
2. 打开 [A02 产业因果模型](阶段A/A02_产业因果模型.md)，按六个专题顺序研究。
3. 在 [A03 数据地图](outputs/阶段A_框架初版/A03_数据地图.xlsx)核实数据口径与可获取性。预填内容来自实施手册，候选来源未验证。
4. 按 [数据规范](数据/README.md)录入事实，再按 A04、A05、A06 形成有证据的状态判断。
5. 重要判断保存到 A07，事后复盘到 A08，新经验进入 A09。

## 实施顺序与完成标准

| 阶段 | 进入下一阶段所需证据 |
|---|---|
| A 无代码模型 | A02六专题明确因果/反例；关键数据可得性核实；A04规则可复算；完成至少一轮预测—复盘—假设的试填 |
| B 数据研究 | 来源和历史版本可追溯；按可用时间对齐；缺失/修订规则明确；完成单变量和历史案例研究 |
| C 状态模型 | 六模块规则冻结并可复现；背离和未知状态可处理；样本外检查完成 |
| D 收益研究 | 按状态统计未来收益、持续期、有利/不利波动；标签窗口与信息集严格分离 |
| E 模拟交易 | State→Signal→Position→Risk分层，包含费用、换月及风险约束 |
