# 钢材产业基本面量化研究系统

以螺纹钢为主要研究对象，研究总资源、卷螺分配、钢材供需、原料、现货、宏观和价格结构。坚持 State ≠ Position，允许 Neutral 与 Unknown。

当前版本：**framework-0.3-candidate**。阶段A—E已有程序，但历史数据时点、因果解释与样本外能力尚未全部验证，当前是研究系统，不是已获实盘准入的自动交易系统。

## 当前入口

- [框架演进与验证契约](阶段A/A05.5_框架演进与验证契约.md)：有效规则、职责顺序、证据分组与验证限制。
- [成本推升参与候选及测试入口](阶段A/A05.6_成本推升参与候选与追高检验.md)：以50%满仓为基准的10%试单/25%确认仓、突破/首次回踩、按实际持仓段检查追高损失。
- [研究假设库](outputs/阶段A_框架初版/A09_研究假设库.xlsx)：候选假设与正式化状态。
- [模型版本记录](版本/模型版本记录.md)：模型迭代与框架演化历史。
- [框架实施说明](研究/架构审查/20260923_框架演进实施与验证.md)：本轮修改、实际验证和剩余边界。

## 运行验证

```bash
.venv/bin/python scripts/run_framework_experiment.py
.venv/bin/python -m pytest -q tests/test_framework_evolution.py
```

运行会在 `研究/回测实验/` 新建独立目录，包含冻结预测、后验复核、代码快照、数据指纹、同条件对照和实约成交。默认从2021年开始，历史资料仅用于探索性评估；不覆盖旧结果，不写入真实交易台账。已有数据截至2026-09-22，本轮没有新增外部数据请求。

## 模块职责

|目录|用途|
|---|---|
|阶段A/|因果框架、状态契约、信任与验证协议|
|stage_b/|数据加载、派生特征与旧评分研究|
|stage_c/|状态、机制候选、物理结果确认与风险判断|
|stage_d/|条件收益、持续期与路径统计研究|
|stage_e/|信号、仓位、真实合约模拟执行与绩效|
|数据/|既有原始、加工、状态数据；各自保留口径|
|研究/回测实验/|每次独立实验及可复现证据|
|交易/|实际交易台账，禁止回测覆盖|
|版本/|模型版本记录与演进轨迹|

旧版9年全胜、净值7.7954及参数高原声明见[历史存档](研究/架构审查/README_20260922_历史绩效声明存档.md)。它们受旧实约映射、杠杆差异、重复开发样本等限制，不能沿用为当前模型结论，也不能与不同区间/风险预算的新实验直接相减归因。
