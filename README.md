# 钢材产业基本面量化系统

当前阶段：A｜框架版本：A-scaffold-0.2｜更新日期：2026-09-19

本项目以螺纹钢为核心交易研究标的，建立日线及以上周期的钢材产业基本面量化研究系统，覆盖总钢材资源、卷螺分配、原料成本、库存演变、现货定价、宏观环境以及期货盘面资金博弈。系统支持定性市场状态与连续量化指标的“双轨制”输出，并将黑色五大品种（螺纹 RB、热卷 HC、铁矿 I、焦煤 JM、焦炭 J）的盘面投机度与交易所会员席位持仓纳入统一微观流动性与风控架构。

## 从这里开始

1. 阅读 [A01 策略总纲](阶段A/A01_策略总纲.md)，了解量化边界、双轨制输出与防未来函数原则。
2. 打开 [A02 产业因果模型](阶段A/A02_产业因果模型.md)，按六个专题顺序研究。
3. 在 [A03 数据地图](outputs/阶段A_框架初版/A03_数据地图.xlsx)查阅已扩充验证的 155 项核心指标（涵盖成材、铁水原料、动力煤及黑色五品种期货盘面）。
4. 查阅 [A05.1 模型量化输出规范](阶段A/A05.1_模型量化输出与指标设计规范.md)与 [A05.2 黑色五品种期货资金投机度规范](阶段A/A05.2_黑色五品种期货资金投机度与量化对比规范.md)。
5. 按 [数据规范](数据/README.md)录入事实，通过 [scripts/fetch_futures_ranking.py](scripts/fetch_futures_ranking.py) 采集龙虎榜，再按 A04、A05、A06 形成有证据的量化输出。
6. 重要判断保存到 A07，事后复盘到 A08，新经验进入 A09。

## 实施顺序与完成标准

| 阶段 | 进入下一阶段所需证据 |
|---|---|
| A 无代码模型 | A02六专题明确因果/反例；关键数据可得性核实；A04规则可复算；完成至少一轮预测—复盘—假设的试填 |
| B 数据研究 | 来源和历史版本可追溯；按可用时间对齐；缺失/修订规则明确；完成单变量和历史案例研究 |
| C 状态模型 | 六模块规则冻结并可复现；背离和未知状态可处理；样本外检查完成 |
| D 收益研究 | 按状态统计未来收益、持续期、有利/不利波动；标签窗口与信息集严格分离 |
| E 模拟交易 | State→Signal→Position→Risk分层，包含费用、换月及风险约束 |
