# Agent 交接协议

本目录是 Codex、Antigravity 或其他 agent 之间的唯一交接位置。交接内容必须写入文件，不能只留在聊天记录中。

## 每次开始任务

1. 阅读项目根目录 `AGENTS.md`。
2. 阅读 `交接/当前状态.md`。
3. 阅读 `交接/任务队列.md`，认领一个明确任务。
4. 检查 `交接/变更日志.md` 最近记录，确认没有其他 agent 正在修改同一文件。
5. 阅读任务涉及的阶段 A 文件、研究报告或数据回执。

## 每次结束任务

必须更新：

- `交接/当前状态.md`：完成了什么、当前结论、下一步和阻塞项。
- `交接/变更日志.md`：日期、agent、修改文件、修改目的、验证结果。
- `交接/任务队列.md`：把任务标记为已完成、进行中或阻塞。

如果产生了新的研究判断，另外更新对应的 A07、A08 或 A09 文件。不要只更新交接文件而不更新正式项目文件。

## 文件锁定规则

当前项目尚未使用 Git worktree。多个 agent 可以读取同一目录，但同一时间只能有一个 agent 修改同一个文件。

开始任务时，在 `交接/任务队列.md` 写入：

```text
认领人：<agent名称>
任务：<任务名称>
目标文件：<文件路径>
开始时间：<时间>
```

结束任务时清除“进行中”状态并写入结果。遇到阻塞时保留任务认领，写清阻塞原因和需要谁处理。

## 交接内容要求

每次交接必须包含：

- 当前项目阶段和模型版本。
- 已完成的具体文件和内容。
- 使用的数据来源、查询日期和数据口径。
- 已验证事实与尚未验证的假设。
- 权限、网络、数据缺失或工具限制。
- 下一步唯一优先任务。
- 不应重复执行的事项。

## 外部 agent 的启动提示

将下面的内容作为 Antigravity 的首条任务说明：

```text
你正在继续钢材产业基本面量化系统项目。

项目目录：/home/hw/项目/钢材产业系统量化模型

请先阅读：
1. AGENTS.md
2. 交接/当前状态.md
3. 交接/任务队列.md
4. 交接/变更日志.md
5. 与任务相关的阶段A文件和研究报告

开始前先在交接/任务队列.md认领任务，确认目标文件没有被其他agent占用。
完成后必须更新交接/当前状态.md、交接/任务队列.md和交接/变更日志.md。
不要删除历史回执、预测快照或研究记录。不要把缺失数据解释成中性，也不要把市场状态直接当成持仓。

当前任务：请读取交接/任务队列.md中分配给你的任务并继续。
```
