# 钢材产业基本面量化系统：外部架构师 Agent 协作与推演设计指南

本文档专为**高推理能力外部大模型（如 Claude 3.7 Sonnet、DeepSeek R1、OpenAI o1 等）及协助协作的朋友**编写。本系统当前处于**阶段 A（无代码模型建设与数据覆盖核查）**，旨在借助更强大的模型智慧，在“顶层架构、产业因果逻辑、指导性指标体系、行情可能性推演树”上实现高水准设计。

## 二、 系统核心定位：非交易执行，聚焦推演与指导

本项目明确确立**“投研决策辅助与产业推演引擎”**定位，不开发全自动做单交易系统：

1. **核心使命**：
   - **指导性指标体系**：输出穿透表面数字、揭示供需边际张力与成本支撑弹性的高阶复合指标；
   - **行情可能性推演**：输出结构化、条件分支明确的行情演化路径预测（情景树），指明关键转折哨兵与证伪红线。
2. **核心研究铁律（违反即视为无效设计）**：
   - **`State != Position`**：市场状态、推演判断与实际交易严格分离；
   - **指标必须分层**：任何指标必须区分绝对水平（Level）、一阶斜率（$\Delta$）、二阶加速度（$\Delta^2$）与季节性偏离度（Z-Score）；
   - **严禁未来函数**：推演只能使用当时时点切实已发布的数据；
   - **允许 `Unknown` 与 `Neutral`**：数据缺失或未到发布节点时严禁补零或假定中性；
   - **先因果、后数据**：禁止“先用统计找赚钱因子再拼凑经济解释”，必须先明确产业传导中介与历史反例。

## 三、 当前数据观测能力与盲区清单（Data Observability & Boundary）

为避免外部 Agent 设计出无法落地的“空中楼阁”指标，系统已完成全量接口实测，数据能力与盲区边界如下：

### 1. 【高频核心观测资产】（日频 / 周频，真实可得）
- **成材周度产销存（周频，每周四/五更新）**：
  * 五大成材（螺纹/线材/热卷/冷轧/中厚板）：主要样本钢厂周产、产能利用率、厂库、社库、周度表观需求测算；
  * 唐山钢坯：方坯主流出厂价、唐山仓储总库存（含象屿正丰库）、调坯轧钢厂开工率。
- **现货价格与期现结构（日频）**：
  * 全国核心城市现货基准价（上海/北京/广州/唐山）；
  * 螺纹、热卷期货主力及近月合约量价、持仓量、注册仓单；
  * 期现基差、月间价差（1-5、5-10、10-1）、卷螺现货及盘面价差、冷热价差。
- **原料与动力煤成本锚（日频 / 周频）**：
  * 铁矿：青岛港PB粉车板价（核心定价锚）、迁安铁精粉、普氏/FOB指数；CDFI西澳/巴西海运费日指数、BDI；
  * 焦煤：甘其毛都口岸蒙5#出厂价（边际定价核心）、唐山沙河驿到厂价、山西主焦煤市价；
  * 焦炭：日照港准一级平仓价、钢联测算吨焦平均利润；
  * 动力煤：秦皇岛港Q5500平仓价、鄂尔多斯车板价、秦港库存、重点电厂周度日耗与存煤可用天数；
  * 废钢：张家港重废市价、唐山重废市价、沙钢重废挂牌采购调价。

### 2. 【低频宏观与外生变量】（旬频 / 月频）
- 统计局/中钢协：月度粗钢与生铁产量、重点钢厂旬度粗钢日产与库存；
- 宏观景气：官方制造业PMI、钢铁行业PMI（含新出口订单指数、生产指数、积压订单）；
- 外生需求：海关总署月度钢材出口总量与金额、全国造船完工/新接/手持订单量。

### 3. 【明确盲区与限制】（必须使用代理变量，不可作为硬指标依赖）
- ❌ **微观终端真实领料**：无工地日度实际出库，只能以周度“表观消费量”作为代理；
- ❌ **废钢钢厂日耗与到货明细**：细分代码受权限限制，需使用“沙钢采购调价节奏 + 电炉开工率 + 螺废价差”旁路推断；
- ❌ **热卷高频海外接单实物吨数**：无日度实物订货簿，以出口订单PMI + 内外卷价差（FOB折算）作为代理；
- ❌ **家电高频排产与内销**：仅能获得月度空调/冰箱产量，不可依赖高频排产数据。

## 四、 黑色产业推演的特殊约束（硬规则）

外部 Agent 在构思推演逻辑时，必须严格遵守以下产业约束：

1. **推演时间视界（Horizon）**：
   * 锚定在 **1~4 周（周度产业验证周期）**。
   * 以每周五的五大材产销存为核心验证节点，不推演日内微观噪音，也不泛泛推演年度宏观。
2. **农历日历对齐（Seasonality by Lunar Calendar）**：
   * 黑色需求受春节停复工影响极大，严禁直接使用公历 1-2 月同比；
   * 必须以农历除夕（大年三十）为 $T=0$ 轴：
     * $T-4$ 周至 $T-1$ 周：工地停产、冬储博弈、钢厂被动大幅累库；
     * $T+1$ 周至 $T+2$ 周：民工返岗、电炉复产、预期博弈期；
     * $T+3$ 周至 $T+6$ 周：**金三银四旺季需求验证期（表需去库加速度定胜负）**；
     * 6-8月：梅雨高温淡季，施工受阻，易出深贴水；
     * 9-10月：秋季赶工旺季（金九银十）；
     * 11月至次年3月：采暖季限产与冬储定价期。
3. **主力合约（01 / 05 / 10）异构性**：
   * **05 合约（旺季合约）**：核心博弈“春节后复工成色与金三银四需求弹性”，交易强预期向现实的兑现；
   * **10 合约（秋季合约）**：核心博弈“梅雨淡季后的秋季旺季与下半年宏观政策加码”，估值弹性大；
   * **01 合约（冬储合约）**：核心博弈“采暖季限产与钢厂冬储博弈”，现实多为淡季，易出现深贴水震荡。
   * 推演树必须明确**针对的具体合约**，不可混为一谈。

## 五、 指导性指标与推演决策树契约规范

### 1. 指导性复合指标设计模板（A04 标准）
针对每个提议的复合指标，必须提供以下规范定义：
- **指标名称**：如“华东长短流程成本剪刀差与边际停产弹性”
- **经济机制**：阐述为什么该指标具有因果穿透力；
- **计算逻辑/代理公式**：使用上述可得数据表达计算方法；
- **分层特征**：定义其绝对水平临界值、变化斜率 $\Delta$ 与加速度 $\Delta^2$；
- **预警信号与失效边界**：在什么情况下发出偏强/偏弱预警？在什么反例下失效？

### 2. 行情可能性推演卡片样板间（A05 / A07 交付标准）

```markdown
### 【推演卡片：以某时点行情推演为例】

#### 1. 产业基本面定位与核心矛盾
- 观测基准日期 / 针对主力合约：[如：2026-03-20 / RB2605]
- 核心矛盾定义：[如：长流程铁水成本高企 vs 下游表需超季节性恢复的估值修复张力]
- 关键指标评分：
  * 长流程铁水完全成本：[支撑强]
  * 卷螺利润差与流向倾斜：[铁水向热卷倾斜，螺纹边际减量]
  * 季节性表需去库加速度：[$\Delta^2 > 0$，超历年同期中位数]

#### 2. 行情可能性情景推演（三条路径）
- **情景 A【基准情景：需求证实，基差修复上行】（概率：60%）**
  * 传导逻辑：金三银四表需环比持续抬升，社库去化斜率陡峭，长流程成本提供强底，盘面向现货平水修复；
  * **哨兵指标 1（Trigger）**：周度五大材螺纹表需保持在 > 310 万吨/周，且环比增幅连续 2 周 > 3%；
  * **哨兵指标 2**：唐山调坯轧钢开工率回升至 55% 以上；
  * **证伪红线（Falsification）**：周表需环比出现负增长，或社库去化发生停滞。
- **情景 B【负反馈击穿：成材拖累原料踩踏】（概率：25%）**
  * 传导逻辑：高炉不减产导致成材库存挤压，盘面深贴水迫使钢厂主动检修，原料端（铁矿/双焦）补跌；
  * **哨兵指标**：青岛港PB粉日度成交量断崖且铁水日产跌破 220 万吨；
  * **证伪红线**：钢厂现货利润快速回正。
- **情景 C【供给挤仓脉冲】（概率：15%）**
  * 传导逻辑：环保临时限产或外生供给收缩导致可交割优质品紧缺；
  * **哨兵指标**：注册仓单持续净流出 + 05-10月差转为显著升水结构（Backwardation）。

#### 3. 投研决策关注点
- 重点盯防时点：[本周四 14:00 钢联周度产销存数据]
- 潜在风险排查：[北方重污染天气预警是否提前解除]
```
