     - **投机账户物理交割防线 (`FORCED_DELIVERY_EXIT`)**：$DTE_{front} \le 20$ 自然日，次日开盘强制双腿同时全平退出；
  4. **双腿对冲撮合与大边保证金结算 (`execution_engine.py`)**：

## 2026-09-22 阶段 E 成本推升双驱与假突破甄别机制升级 (Stage-E-0.6-cost-push-dual-drive / T-STAGE-E-006)

  2. **经济因果根因解构**：
     - 在原料（铁矿、双焦）因外生供给冲击（如 2019 淡水河谷矿难、2021 煤炭保供前夕、2023 煤矿事故严监管）暴涨时，钢材成本线被动抬升；
     - 此时下游建材终端往往因高价抵触、按需采购，导致螺纹表需（FBS）打分低迷呈现负值；

  3. **真假突破关键鉴别体系**：
     - **持续型成本推升 (Sustained Cost Push)**：原料供给短缺真实存在，高成本向下顺畅传导，现货跟涨且基差坚挺 (`pct_basis_1y >= 0.40`)，杭州出库微观流速健康 (`pct_flow_hz_outflow >= 0.30`)，价格维持在现金成本线上方；
     - **假突破型推升 (False Breakout)**：纯盘面情绪炒作，现货严重跟不上，盘面深升水导致基差塌陷 (`pct_basis_1y < 0.25`，现货深度贴水超过 -80~-150 元)，下游抵触采购导致负反馈隐患积聚。
- 核心落地组件与规则改造：
  1. **防守端：原料挤仓禁空保护 (Defensive Veto)**：
     - 当原料端呈现显著成本推升剪刀差 (`cost_push_spread_5d > 0.015`) 且领头羊为原料品种时，即便成材表需评分低迷，坚决一票否决做空 (`FLAT`)，禁止在成本上升期逆势做空；
  2. **进攻端：成本推升顺势买入 (Offensive Cost-Push Long)**：
     - 在 `is_sustained_cost_push` 状态下，价格在 MA20 附近安全带内 (`abs(dev_ma20) <= 0.035`) 突破旧有 `fdir == "Bullish"` 限制，正式激活 `LONG` 开仓；
  3. **假突破一票否决追多 (False-Breakout Veto)**：
     - 当处于假突破推升或盘面透支升水时 (`is_false_breakout_cost_push` 或 `pct_basis_1y < 0.25`)，安全垫引擎一票否决追多；
  4. **底层 Bug 修复**：
     - 修复 `stage_c/risk_firewall.py` 第二重原料隔离中直接提取 `feature_row.get("squeeze_index")` 导致的列名失配（特征宽表中为 `i_squeeze_index`, `jm_squeeze_index`, `j_squeeze_index` 与 `is_raw_material_squeeze`），彻底恢复原料逼仓风控拦截。
