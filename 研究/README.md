# 研究流程

每次先明确一个研究问题，检索已有案例与A09，记录当前模型版本。研究证据应能定位到数据版本和当时可用时间。

1. 固定问题、经济逻辑、替代解释和失效条件。
2. 冻结数据口径、样本划分、观察窗口和候选参数。
3. 分开保存历史验证与样本外验证；样本外不得参与调参。
4. 保存支持案例、反例及结果不确定的案例。
5. 更新对应A文件和A09；只有验证通过的规则才能进入正式版本。

预测快照使用P-YYYYMMDD-NNN标识，只新增不覆盖；更正生成新ID并引用原ID。复盘E记录引用P，假设H引用E或案例；正式模型版本引用H及验证材料。
