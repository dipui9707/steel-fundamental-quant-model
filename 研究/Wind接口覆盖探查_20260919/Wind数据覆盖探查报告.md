# Wind MCP 数据覆盖探查报告

探查日期：2026-09-19｜状态：DONE_WITH_LIMITS｜性质：接口与账号权限验收，不是市场判断

## 结论

当前 Wind MCP 能提供本项目宏观、总供给、卷螺产销存与价格的大量基础数据。实测取到 **49条序列**；但当前账号下未取得可用的卷螺利润对、独立电炉利润和废钢到货量，准确热卷出口订单/实时FOB报价也未匹配到。历史逐条发布时间、修订版本及具体期货合约映射未随本次数据返回。

因此可以继续做数据口径审查和当前状态研究；尚不足以直接构成避免未来函数的完整历史回测数据库。

## 本轮范围和取数规模

- 使用 `economic_data.search_economic_indicator` 查元信息，用 `query_economic_indicator_data` 验证数值。
- 保存36份完整请求/回执，另有1次初始PMI元信息连通探针，合计37次调用。共28次搜索、9次取数。
- 搜索原始结果去重后有141个代码，包含不相关、预测及陈旧候选，不能将此数量视为有效覆盖。
- 取数尝试55个唯一代码，49条返回数值，6条被明确提示无权限。
- 请求优先使用最近3期；发现混频返回扩展后改为2026-09-10至09-18或2026-08-01至08-31短区间。共收到850个日期—数值对，最长单序列65个交易日，未做全历史拉取。

## 缺口二：搜索未找到准确口径

- **热卷出口订单**：两轮搜索未返回对应品种订单。精查返回宏观企业家出口订单指数M5527688，不能冒充热卷订单。
- **热卷实时FOB报价**：只返回海关月度出口平均单价及商品编码，如P0344100。已成交出口均价不能作为实时订单报价。
- **长流程卷螺利润**：精查仍返回百川“毛利”；既有权限限制，也缺少成本模型、税费、原料配比、即时/滞后成本定义。
- **指定原料基准**：青岛港PB粉61.5%、唐山准一级焦未精确匹配；当前可取领先价格、二级焦以及未明确地区品级的废钢价格，需先确认适用性。
- **热卷出口总量**：已取热轧薄板出口量，但覆盖热卷的商品编码集合、交叉重叠与历史编码变更尚未核实。

这些是“本轮搜索未匹配/口径待确认”，不能断言Wind完全不提供。

## 缺口三：模型必需的时间与结构信息

1. **逐条available_date**：实际序列只有meta和date/value数组，updateDate是序列层字段，不能给历史每个观测当作首发时间。
2. **历史修订版本**：本次未返回vintage、初值/修订标识和历史发布时间链。检索元数据起点不能证明历史点时可得。
3. **期货合约映射**：已验证EDB活跃合约序列，当前技能路由表没有专门的期货逐合约行情服务。本轮未验证合约ID、主力切换规则、复权与完整OHLC。
4. **生产分配机制细节**：厂级产线可切换能力、订单、检修和生产约束未进行专项查询；聚合序列不能替代这些因果证据。
5. **政策和信息响应标签**：本轮未调用financial_docs新闻接口，不能判为缺失；仍需事件时间戳和人工分类，才可构造信息响应状态。
6. **地区价差与完整黑色广度**：本轮未专项验证，不应记为接口缺失。

## 接口行为与接入注意事项

- 搜索支持自然语言，但多指标问句可能只召回其中一部分，也会出现其他国家、企业、过期或一致预测指标。单独精查有用：厂库和基建是在第二轮找到。
- **搜索可见不等于数值可取**。部分调用外层isError=false，但内容summary明确写“受限指标已剔除”，必须逐个核对请求代码与返回代码。
- **混频observation不可靠地等于每条N个观测**。例如请求3期时，产业批次的周度铁水返回14条，价格外需批次日价格返回65条、热轧薄板仅2条。无法据此确定内部实现，后续应按频率拆分并使用显式短区间、验收条数。
- 元数据的freq也可能不足以表达真实周期，例如粗钢重点企业候选出现“日/周”标签和旬末日期。正式接入需检查真实日期间隔。
- 本轮未以不同来源混算库存、表需、利润，也未把样本写入正式市场事实库。请求和回执均保留在研究目录，便于审核后再入库。

## 下一步的数据接入优先级

本段是依据实测覆盖形成的项目实施建议，不是Wind返回的投资结论。

1. 优先冻结能够实际取得的宏观、247家供给、卷螺产量/厂库/社库、表需、成交和现货的代码与口径。先解决周四/周五统计区间及数据来源样本一致性。
2. 单独处理利润与废钢到货权限；若无法获取，保留缺失并补充自有数据。自算利润必须先明确成本模型，不能以卷螺价差代替。
3. 核实热卷外需的海关编码集合及订单/报价来源，并建立发布时间/修订版本记录方案。
4. 准备进入代码阶段时，再决定逐合约行情来源和换月规则。本轮数据仅支持接口验收与口径研究，未完成历史数据质量审计。
