# 钢材产业基本面量化投研与策略系统 (Steel Fundamental Quant System)

本项目以**螺纹钢期货（RB）**为核心交易标的，热轧卷板（HC）与铁矿、双焦为关联博弈品种，构建日线及以上周期的黑色金属产业基本面量化研究与策略交易系统。

系统从顶层产业因果经济学出发，严格恪守 **`State != Position`**（市场状态、策略信号与实际持仓解耦）与 **`Point-in-Time (PIT)` 绝对零未来函数** 铁律，贯穿“原始事实 $\to$ 衍生加工 $\to$ 状态识别 $\to$ 风控防火墙 $\to$ 策略执行与盯市撮合”全闭环。

当前系统已全面完成阶段 A 至阶段 E 的体系构建，模型版本正式封板为 **`Stage-E-0.11-carry-regime-adaptive-sizing`**。

## 二、 核心机制创新与护城河体系

系统的核心竞争力在于构建了**“产业因果 + 物理现货真实现金流 + 微观结构 + 期限结构”**的深度融合体系：

1. **实物现货真实利润校验与盘面深贴水解耦 (`Spot Profit Decoupling`)**：
   - 彻底解耦盘面虚拟毛利与钢厂实体高炉利润（`profit_bf`）。当盘面深贴水制造“虚假深度亏损”幻觉但现货仍在赚钱时（如 2025 年），放行顺势做空，坚决不被虚假成本底绑架。
2. **防震荡绞杀双重防御门禁 (`Anti-Chop Defense Gates`)**：
   - **方法 1：20 日箱体空间与盈亏比不对称门禁 (`Box Space & RR Gate`)**：基于严格 T-1 滚动高低点，当距离箱体下轨不足 1.2% 且反弹阻力风险超过下行空间 2 倍时，一票否决做空（天花板追多对称拦截）；破位真突破与在持单 100% 豁免。
   - **方法 2：微观实物流动性冰封门禁 (`Physical Liquidity Gate`)**：在农历春节前后（`cny_week` $\in [-4, +3]$），若全国主流建材日成交量分位数 $\le 0.10$（实体停工冰封期），一票否决建立新开趋势仓。
3. **期限结构 Carry 顺逆风安全垫与自适应仓位调节器 (`Carry Adaptive Engine`)**：
   - **极端逆风一票否决**：强 Backwardation（展期分位 $\ge 0.85$）否决做空杀跌，强 Contango（展期分位 $\le 0.15$）否决追多；
   - **自适应杠杆管理与高波动硬隔离**：常态顺风加成 1.05x，轻度逆风削减至 0.85x；在高波动脱困区（`vol_shock_ratio >= 1.40`）与逼空侦察仓阶段，强制锁定 $\le 1.0x$，绝不放大黑天鹅风险。
4. **五重风控防火墙与破位熔断 (`Risk Firewall`)**：
   - 数据真空降级、原料逼仓隔离、波动率脉冲熔断、技术破位硬止损（MA20/MA60）、同尺度背离阶梯惩罚，拥有超越一切信号的最高否决权。
5. **参数高原与防过拟合验证 (T-STAGE-E-013 全景实证)**：
   - 121 组独立全历史连续回测，净值变异系数 CV 仅 **0.189**（远低于 0.35 脆弱线），全区间夏普均值 **0.74**，**86.0% 的参数配置保持 9 年全胜，100.0% 保持 8 年以上正收益**，实证证明系统处于宽阔平坦的“产业因果参数高原”。

## 四、 快速上手与常用流水线命令

```bash
.venv/bin/python scripts/run_parameter_robustness_test.py

# 4. 运行全系统自动化单元测试套件 (核验 81 项测试全绿)
.venv/bin/pytest tests/

# 5. 执行期货日度全自动采集与官方结算价校准流水线 (盘后更新)
bash run_daily_futures.sh
```
