# A01 策略总纲

状态：手册整理稿｜依据：项目指导与实施手册 V0.2 第1—4、17—19节

## 目标与边界

服务螺纹钢日线及以上行情研究，典型观察窗口为5—20个交易日，可随产业矛盾持续性延长。模型回答方向、强度、持续性、生命周期和可信度。它提供产业方向先验，不直接决定持仓。

State ≠ Position。允许中性；证据不足使用“未知”，不能把缺失数据解释为中性判断。模型输出全面采用“双轨制”（离散状态向量 + 连续量化指标，详见 A05.1），并将黑色五大品种（RB、HC、I、JM、J）期货资金投机度与交易所会员持仓作为微观流动性与风控滤网（详见 A05.2 与 TqSdk 管道）。

## 六模块契约

| 模块 | 输入范围 | 输出职责 |
|---|---|---|
| 宏观与外部环境 | 政策、地产基建、汇率、贸易、外部事件 | 外部驱动是否覆盖产业逻辑 |
| 产业基本面 | 总资源、卷螺分配、需求、库存、利润 | 景气度评分($FBS$)、动量斜率($FV$)、加速度($FA$)与供需归因 |
| 现货状态 | 现货价格、基差、区域差、成交与库存 | 产业公允估值偏离率($VG$)，现实是否确认产业判断 |
| 情绪与持仓 | 五品种VOI、沉淀资金、量价仓打标、席位集中度/净偏度 | 资金进攻龙头、投机过热预警、逼仓结构与筹码拥挤度 |
| 价格结构 | 趋势、突破、波动、月差期限结构、背离积分面积 | 价格对判断的确认与背离量化($DA$) |
| 模型信任 | 内部一致性、现货/价格确认、宏观冲击、数据质量、极端席位拥挤 | 当前解释力可信度评级、真空期降级模式与风控开仓硬禁令 |

## 研究纪律

先因果、后数据；先状态、后交易；先解释、后优化；先验证、后加入。禁止永久赋予单指标多空意义。持续背离需要降低信任，新经验先进入A09。预测快照保留当时的信息，不以事后资料改写。
