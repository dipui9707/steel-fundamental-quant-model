# A04 状态变量手册

状态：计算规范草案，尚未校准或验证｜依据：手册第6—8节

## 时间和样本前提

判断时点记为 T，仅使用 available_date ≤ T 且 recorded_at ≤ T 的观测版本。修订数据不能覆盖初值。对同一序列、同一data_date，选择T时已知的最新版本。历史补录若有可靠的原始发布存档，可单独建立重建信息集并标明，不能冒充当时真实记录。

同一序列由变量ID、来源、单位、样本范围、频率和合约/地区等维度共同确定。不同系列不得直接相减。周度变化按原生周频计算，再映射到日度判断；不得对向前填充的周值计算“日变化”。

## 基础转换定义

| 状态维度 | 定义 | 缺失与边界 |
|---|---|---|
| Level | 本次可用原生周期观测 x_t | 缺失输出Unknown |
| ΔLevel | x_t − x_(t−1) | 任一期缺失则不可计算，不跨缺口当相邻期 |
| Δ²Level | (x_t − x_(t−1)) − (x_(t−1) − x_(t−2)) | 必须连续三个相同口径周期 |
| 历史分位 | [样本中小于x_t的个数 + 0.5×等于x_t的个数] / N | 比较样本仅含此前可用观测，不含当前值 |
| 季节性分位 | 同上，历史样本限定为历年可比季节窗口 | 春节错位单独处理，样本不足输出Unknown |

变化符号可描述增加/减少/不变，加速度仅描述变化幅度，不能直接映射多空。库存Δ<0且Δ²<0可描述为去库加速，但其产业含义仍需供应和需求拆解。

## 加工指标口径

- 总库存 = 社会库存 + 钢厂库存，仅在无重叠且样本一致时计算。
- 表观消费 = 本期产量 − (本期库存 − 上期库存)，先核实是否需纳入进出口及统计调整。
- 卷螺利润差 = 热卷同口径吨钢利润 − 螺纹同口径吨钢利润。
- 卷螺产量占比 = 热卷产量 / (热卷产量 + 螺纹产量)。这仅是两品种内部结构，不等于全钢材资源分配比例。
- 基差 = 可比现货价格 − 对应期货合约价格。地区、品质、税费、运输及交割调整方法需记录。
- 高阶衍生指标统一采用 [A05.1 候选数学规范](A05.1_模型量化输出与指标设计规范.md) 与 [A05.2 微观数据契约](A05.2_黑色五品种期货资金投机度与量化对比规范.md)，旧简式在本版本撤销，不并行生效：
  1. FBS 仅含去重后的实物供给/需求/库存证据。成本、宏观、价格和基差独立列示，0分不是物理供需平衡。
  2. 动态总分变化分成数据变化 D 与调权 W；FV 对 D 求均值，FA 对同尺度 FV 求差。没有新发布的周值沿用不构成新的产业证据；规则换版后重置连续段。
  3. 现金成本是有口径前提的参考值；fair_value_price / valuation_gap_ratio 当前为 null。未校准系数不构成公允价值或止跌线。
  4. 背离用同窗口、无量纲的价格变化与实物变动比较，取消元/吨与评分直接相减。累计面积、经验分位、Z分数分别命名；极端背离不保证反转。
  5. 库存水平与变化的季节分数分开，用判断时点可得历史版本；春节除夕对齐及最小样本/零标准差规则须明确。
  6. CDE仅度量有方向证据之间的分歧，必须同时给出中性比例、方向比例与覆盖率；全中性和全缺失不是高置信度一致。
  7. ERR分为err_down与err_up，是机制压力指数，非概率；关键激励/产能/可实施条件缺失则为null。
  8. VOI为统一单/双边口径后的成交持仓比，不用固定1.5认定投机过热；保证金规模变化是名义代理，不是净资金流入。
  9. IMM原式仅是期货价格组合残差，未扣加工成本，不能以零为钢厂亏损线；同期限卷螺差不能直接证明产量转移。
  10. TNB为披露前20多空持仓差额相对同日同合约OI；CS在原公式下等于TNB，不能重复计权；会员不等于产业/投机客户，榜外值保留未知。


## 使用边界

以上给出可复算定义，不预设30/70分位或固定天数等未经验证的参数。参数进入正式模型前，应在A09记录验证及反例。参数未确定、输入不足或过期时，状态为Unknown；Neutral仅表示已有充分数据支持“无明显方向优势”。历史版本、预测快照与标签隔离统一见 [A05.3](A05.3_回测验证与预测快照协议.md)。本次为架构候选修订，所有新参数未进入正式模型。
