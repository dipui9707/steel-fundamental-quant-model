# A05.3 回测验证与预测快照协议

状态：架构候选协议 `ARCH-REVIEW-20260920`，尚无真实历史回测结果。负责 T-ARCH-004。替代 A05.1 原第四节的粗略检验约定；不改变正式模型版本，不生成交易指令。

## 1. 先确定研究对象

主研究对象是 RB 单品种的**时间序列 Rank IC**：某项特征在不同判断时点的排序，与随后收益排序是否相关。155 个指标不是 155 个可交易资产，不可把它们排成“每日截面 IC”。五品种截面 IC 只能作独立的探索性研究，K≤5、共同产业暴露强，不能据此声称稳健选品种能力。

分开检验三类结果：

1. **产业机制**：例如订单/利润变化后，受约束产线是否实际调整产量；未来铁水、产量、库存是结果标签。
2. **价格预测**：FBS、FV、FA、VG、TNB 与未来 5/10/20 交易日价格变化的关系。
3. **风险提示**：拥挤预警、背离、Unknown 是否有增量解释力。只比较风险事件发生率和误报漏报，不能把拒绝输出后的剩余样本收益当整体绩效。

本阶段没有完整价格与发布版本库，以上都只是预注册协议。费用、仓位、换月交易盈亏另属阶段 E。

## 2. 可用时间、版本与信息集

每条原始观测至少包含：

| 字段 | 含义与约束 |
|---|---|
| observation_id / series_id | 观测版本唯一 ID；series_id 包含来源、品种、单位、地区、样本、频率、合约 |
| data_date / period_start / period_end | 归属期；不能替代发布时点 |
| available_date | 该版本实际公开/供应商可获得时点，带时区；不明保留 null |
| recorded_at | 本系统实际采集/记录时点，带时区 |
| revision_id / supersedes_id | 修订版本及其前序版本，不覆盖旧文件 |
| source_ref / source_hash | 可回查原始回执及内容校验值 |
| value / unit / quality_status | 真零与缺失分开；模拟值标记 SYNTHETIC |

两套信息集不混用：

- `LIVE_RECORDED`：选择 `available_date ≤ T` 且 `recorded_at ≤ T` 的已知最新版本。这是可审计的实盘/前向记录。
- `RECONSTRUCTED_PIT`：允许今天补录历史发布档案，但必须证明**该版本内容**当时可得；保存档案定位与哈希。展示“重建”，不得称为当时已记录。
- 当前查询的修订终值、仅有通常发布时间、仅有 `updateDate` 的序列，一律不进入严格 PIT 回测。只能单独标记 `CURRENT_VINTAGE_EXPLORATION` 作探索。

按 `(series_id, data_date)` 选版本；并列时间戳无法排序时必须有可信版本序号，否则输出冲突。相同版本ID出现不同内容也必须输出冲突，不能静默任选。

LIVE_RECORDED 中，变换参数、季节性参照、阈值、权重、会员字典、主力映射必须已在 T 前实际冻结。RECONSTRUCTED_PIT 中，今天新设计的算法可进行历史模拟，但参数训练截止与输入可用截止必须早于模拟 T，会员身份等事实性映射仍须证明当时可得；`experiment_frozen_at / computed_at` 如实记录今天，不能回填过去。事后设计的算法不能声称当年已在运行；看过后段行情选择的规则不属于干净历史盲测，按第5节重新留出。

每周重复沿用的值可以用于当日状态显示，但不产生新观测、新斜率或新独立证据。主分析采用每次真实发布后的固定判断时点；日度沿用分析单列并按发布批次与日历块处理相关性。

## 3. 合约与收益标签

在 T 固定具体合约 `contract_at_T`，依据此前已知的成交/持仓与到期规则选择，不事后用全样本“最活跃合约”。五品种比较使用相同可交易时点及预先规定的期限匹配规则，不假定 I/JM/J 与 RB/HC 都是 01/05/10。

`entry_at` 定义为 T 之后、按已冻结交易日历映射的首个合格交易时段开盘，并强制断言 `entry_at > T`。夜盘属于哪个交易日，以交易所日历为准，不能按自然日切割。“下一交易日”的日K开盘可能已在前一自然日晚间发生；若该open早于T就不能使用。只有日K时，须选择事前固定的、日K首时段开盘也严格晚于T的下一个完整交易日；若研究指定后续日盘开盘而日K包含此前夜盘，则必须取得该时段价格，否则标签不可构造。不能把盘后新信息配回当天15:00收盘价。

令 dₑ 是 entry_at 所属交易日，`exit_at(h)` 是 dₑ 起第 h 个交易日的日盘收盘，包含 dₑ，h∈{5,10,20}：

\[
y_{T,h}=\log(P^{close}_{c,d_{e+h-1}}/P^{open}_{c,d_e}).
\]

同时保留简单价格收益 `expm1(y)`。它是固定合约价格变化，不是保证金收益率或策略净收益。研究采用可观察开收盘，不声称能以该价格成交；若扩展成交研究，再加入延迟、滑点、涨跌停与费用。

基准协议**固定合约持有标签、不跨合约拼接**。若合约在标签结束前到期、流动性不合格或缺端点，该标签 `INELIGIBLE_CONTRACT`/`MISSING_PRICE`，记录排除数量及期限分布。缺数据不得偷偷顺延终点。连续合约收益仅可作为另一个明示换月、价差处理、成交成本的研究方案。

每个标签保存 `prediction_id, contract, entry_at, exit_at, entry_price, exit_price, h, label_available_at, label_version`。标签计算可晚于 T，但特征快照不得读取标签。进入训练集须满足 `label_available_at ≤ train_cutoff`；未走完窗口就是 `PENDING`，不是收益零。

## 4. 时间序列 Rank IC、IC_IR 与推断

对一个特征、一个合约处理方案、一个 h、一个预先划定的时间块 B，取有效配对集合 V：

\[
IC^{TS}_{B,h}=Corr\big(Rank_{avg}(x_T),Rank_{avg}(y_{T,h})\big),\ T\in V.
\]

并列值使用平均秩；常数特征/标签的数学相关性未定义。少于3个有效配对时本协议不输出IC（两点虽可算为±1，却不能提供有用的推断）。本协议的推断门槛更严：候选要求每块至少30个有效发布事件、至少5个不同特征值；这只是研究门槛，**不是显著性保证，也未校准**。报告有效对数、原生发布数、缺失数、不同取值数、观察区间和排除原因。

SciPy 官方文档说明常数输入的相关系数未定义，并提醒小样本不宜依赖默认渐近 p 值。本项目存在序列相关，所以不能直接照搬独立样本逐点随机置换。[方法依据：SciPy spearmanr](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.spearmanr.html)

预先定义互不重叠年度块 B₁…Bₘ，各块分别计算 IC；跨块标签先按第 5 节剔除。仅当有效块数 m≥5（候选门槛）且样本标准差非零，报告：

\[
IC\_IR_{block}=mean(IC_{B_j,h})/sd_{sample}(IC_{B_j,h}).
\]

同时列出每块原值。少量年份则只报告块 IC，不制造稳定性结论。该比值**不年化、不乘 √252**，不是 Sharpe，也不是单品种日度“IC均值”。滚动窗口 IC 图仅用于描述，重叠窗口不作为新增独立样本。

不确定性候选方法：按**日历连续块**同步重采样特征、标签、缺失掩码和发布批次，块长度不短于最长收益重叠期与已知信息持续期，并在训练区检查20/40/60交易日等预注册敏感性；统计量每次重新计算排名，按预注册方案形成抽样置信区间。该配对重采样保留原有相关性，**不能直接当作IC=0的零分布计算p值**；若需要检验，必须另定具有时间序列交换性依据的零假设生成/中心化方案。不能把删掉缺值后相邻的两行当连续交易日，也不能分开随机洗牌x/y。保留季节分层，结构断点前后分开报告。有效块过少只报告描述统计与局限。

HAC 只作为另设的等间隔日度回归稳健性分析：例如 `y=α+β x+controls+ε`，冻结变换后检查 β 的 HAC 区间。它不是 Spearman 的现成标准误。至少覆盖 h−1 的重叠滞后并检查更长相关性；不等间隔发布事件不能直接交给等间隔 HAC。[方法依据：statsmodels cov_hac](https://www.statsmodels.org/stable/generated/statsmodels.stats.sandwich_covariance.cov_hac.html)

## 5. 训练、验证与最终保留集

1. 按时间顺序划分训练→验证→最终保留集；禁止随机打散。具体日期待确认实际数据覆盖后预注册，不在无数据条件下虚构样本长度。
2. 每次边界按真实标签区间排除重叠：训练标签 `[entry_at,exit_at]` 与下一块的观测/标签评估区间不得相交，且训练标签已在训练截止日前可得。20 日窗口不能仅“错开一行”。
3. 扩展窗口 walk-forward 只能用过去已成熟标签拟合；如另用含未来训练块的分块交叉验证，必须额外清除所有测试标签重叠样本并设置至少最大标签期限的隔离带。它不能替代严格向前验证。
4. 去极值、标准化、春节对齐历史窗口、特征方向、动态权重、成本参数、事件门槛和滞后搜索都在训练区冻结。最终保留集只评估一次；看过结果再改方案就要改名验证集并另留测试区。
5. 同表报告：纯价格基准、产业单变量基准、静态 FBS、动态 FBS、剔除基差/价格输入版本、加入微观因子版本。动态方案必须解释较简单基准的增量。
6. 记录全部测试次数：155 项不是默认全部入模；3 个期限、若干阈值/时滞构成多个检验。探索结果与预注册主假设分开；验证区执行预定多重比较控制，最终以独立留出证据为准。
7. 报告全体时点与可输出子集的覆盖率、Unknown比例及分母。不能通过剔除困难时期提高“胜率”。条件胜率以全部已成熟合格事件为分母，零收益、成本前后口径明确，附块相关性区间。

## 6. 背离事件与半衰期

**累计背离面积DA在事件内单调累加，本身不能用来估计“减半时间”。** 价格收敛研究须另建水平残差：例如在事件e冻结有效参考锚A_e>0与尺度s_e>0，`g_(e,h)=[log(P_(e+h))−log(A_e)]/s_e`。若A_e来自公允模型，必须先通过该模型验证；没有有效估值模型就不能生成VG半衰期。采用其他统计参考价，必须另命名为“相对冻结统计锚的收敛”，不得称价值修复。

A05.1的u−v是**滚动变化差**，旧冲击自然滚出窗口就会衰减。可以独立研究其“动量差消退时间”，但不能直接当成上述水平价格收敛或公允回归。

事件开始：过去训练样本冻结的 |g| 门槛 q 被首次穿越、此前处于可启动状态且没有未结束同类事件。事件结束/冷却/重新进入规则在看结果前登记，连续 10 天超阈值仍只算一次事件。

在事件 e 的起始时点冻结参考锚/标准化尺度及方向 sₑ=sign(gₑ)，定义“半幅收敛”的首达时间：

\[
\tau_{1/2,e}=\inf\{h\ge1:s_e g_{e+h}\le |g_e|/2\}.
\]

负向越过零也算穿越半幅，但另外记录 `overshoot`、最大不利偏离与最终方向，不能把反向崩溃写成盈利。若采用滚动估值锚，必须另外分解价格变化与估值模型重估贡献；主基准采用事件起点冻结锚。

逐事件同时登记5/10/20交易日内是否收敛、首次收敛用时、区间内最大恶化、失效/缺失/到期。固定观察上限或资料期末未收敛属行政性右删失；政策打断、合约换月、供应口径变化、失效后停止观察可能是信息性删失，必须单列竞争事件或提供最坏/最好边界，不能直接当作普通删失并宣称无偏。中间缺观测、恢复后见到阈值内时，首次穿越仅能定位在两个观测时点之间，不得把恢复日伪装成精确首达日；主基准在首缺失前停止精确跟踪并列为缺失中断，另做区间删失/上下界敏感性。

仅在可辩护的非信息性删失条件下，按事件首达时间建立 Kaplan–Meier 的未收敛生存函数，报告 `1−S(5/10/20)` 和到 50% 事件收敛的中位时间。曲线未降至 0.5 则写“观察窗内未达到”，不能只取成功事件均值。还应报告行政删失比例与竞争事件比例。[方法依据：lifelines KaplanMeierFitter](https://lifelines.readthedocs.io/en/latest/fitters/univariate/KaplanMeierFitter.html)

AR(1)半衰期另设探索研究：`g_t=a+φg_(t−1)+ε_t`；只有同间隔、平稳且0<φ<1时 `HL=−ln(2)/ln(φ)`，指**相对长期均值μ=a/(1−φ)的偏离g−μ**在条件期望中的减半时间，单位为采样间隔，不是g必回零。φ≥1无有限收敛解释，φ≤0不是此单调衰减模型。AR半衰期与事件中位首达时间不得互换。

## 8. 推演卡片契约

每张卡片包含 `prediction_id / as_of / mode / evidence_version_ids / model_status / horizon / scenario_set`。每个情景要有：因果链、前置证据、预先冻结的哨兵阈值、发布时间、证伪条件、下一次检查触发事件和缺项。

- 基准：同样本库存、供给、需求链符合已声明机制。
- 下行：需求/价格传导到生产或库存的证伪分支。
- 上行/挤压：微观与现货证据足够时才列，会员持仓不能单独证明挤仓。
- Unknown：关键口径/可用时间缺失；其他可知字段独立展示。

未校准时输出 `scenario_weight=null`；若采用 A05.2 候选软评分权重，则字段明确命名 `scenario_score_weight` 且带 `UNCALIBRATED`，**不能叫发生概率**。不同情景可能重叠或不穷尽，未修正前更不能强制归一成概率。卡片无下单或仓位字段。样例见 [合成推演卡片](../研究/案例/SYNTHETIC_推演卡片.md)。

## 9. 本次验收与后续实施入口

当前交付是公式、时间和事件协议，以及合成反例校验；真实 IC、IC_IR、胜率、成本阈值、传导天数均为 `NOT_RUN`。本地实现顺序：补齐历史发布/版本回执→修复席位数据契约→用小规模真样本生成只读快照→冻结研究清单→执行 walk-forward→人工归因。

验收必须覆盖：晚到发布不得回写早时点；未来修订不改旧快照；周频沿用不算新证据；换月跳空不作为固定合约收益；标签边界重叠被剔除；全常数 IC 不得变零；未收敛事件保留删失；模拟数据不会进入真实台账。合成验证只能证明这些示例约束，不能证明市场有效。
