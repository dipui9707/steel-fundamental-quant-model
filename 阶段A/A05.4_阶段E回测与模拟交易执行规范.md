## 一、 系统架构与执行流向

系统严格遵循以下四级流水线流转：

```text
State (阶段 C 状态矩阵)
  ↓
Signal (阶段 E 策略信号生成)
  ↓
Risk Firewall (A06.1 五重风控防火墙绝对否决)
  ↓
Position & Execution (阶段 E 风险预算、换月移仓与 Next-Bar 撮合)
  ↓
Performance & Attribution (阶段 E 账户复核、绩效评估与交易记录)
```

### 1.1 `State != Position` 铁律贯穿执行
- **状态不等于信号**：基本面处于 `Bullish` 景气状态，不代表立即发出买入信号。必须获得微观现货确认（基差升水或消化顺畅）与盘面动量配合；
- **信号不等于持仓**：生成的交易意图（`BUY` / `SELL`）必须无条件提交给风控防火墙（`RiskControlFirewall`）进行终审。防火墙拥有最高裁决权；
- **持仓不等于执行**：持仓意图需经由资金管理（`PositionSizer`）折算为具体手数，并在下一交易日开盘（Next-Bar Open）以加点滑点撮合。

## 二、 零未来函数 (PIT) 时间戳与撮合协议

依据 A05.3 协议第 2~3 节，坚决杜绝任何偷看未来函数行为：

### 2.1 决策与撮合时空分离
1. **决策时点 ($T$ 日日终)**：
   - 设 $T$ 日为当前交易日，15:00 日盘收盘后，收集截至 $T$ 日已合法公布的 PIT 原始事实；
   - 运行特征宽表计算与状态识别，生成针对 $T$ 日的 `TradingSignal` 与 `FirewallDecision`；
   - 严禁在 $T$ 日决策时使用 $T+1$ 日的任何价格、成交量或事件。
2. **撮合时点 ($T+1$ 日开盘)**：
   - $T$ 日形成的交易指令，在 $T+1$ 日首个交易时段开盘以 **$P_{T+1}^{open}$** 撮合成交；
   - 撮合价格必须加上滑点：买入价为 $P_{T+1}^{open} + \text{Slippage}$，卖出价为 $P_{T+1}^{open} - \text{Slippage}$；
   - 严禁在 $T$ 日收盘直接以 $P_T^{close}$ 无滑点成交，杜绝偷看全天走势后事后下注的假象。

### 2.2 交易摩擦与账户会计模型
1. **滑点模型 (Slippage)**：
   - 螺纹钢每手 10 吨，最小变动价位 1 元/吨；
   - 默认滑点为 1 个最小变动价位（$1.0$ 元/吨），双边收取。
2. **手续费模型 (Commission)**：
   - 采用成交金额的比例费率，基准设为万分之一（$0.01\%$），开平仓双边扣除；
   - 单笔交易手续费：$\text{Fee} = P_{\text{exec}} \times \text{Lots} \times \text{Multiplier} \times 0.0001$。
3. **账户盯市会计恒等式 (Mark-to-Market Identity)**：
   每日日终必须严格满足以下会计恒等式，误差必须等于 0：
   $$\text{Total Equity}_t \equiv \text{Cash Balance}_t + \text{Margin Occupied}_t + \text{Unrealized PnL}_t$$
   其中持仓浮动盈亏（Unrealized PnL）按交易所官方结算价（Settlement Price）每日盯市计算。

## 三、 风控防火墙绝对否决协议

交易执行器必须强制前置集成 `RiskControlFirewall`。防火墙裁决状态优先级定义如下：

| 防火墙状态 | 允许最大杠杆 | 策略执行强制动作 | 经济因果依据 |
| :--- | :--- | :--- | :--- |
| **`TRADING_HALT`** | 0.0 | **强制平仓，系统休克停机** | 关键数据中断超48小时或新鲜度极低，属于信息真空 |
| **`FORCED_LIQUIDATION`** | 0.0 | **无条件即刻斩仓离场，禁开仓，冷却3日** | 遭遇极端反向波动率脉冲（如 924 暴涨）或技术破位 MA20/MA60，坚决止血 |
| **`RESTRICT_CLOSE_ONLY`** | $\le 0.50$ | **锁定仅允许平仓，严禁开立反向头寸** | 跨品种原料逼仓挤仓（严禁做空成材），或同尺度中度背离 |
| **`CAUTION`** | $\le 0.70$ | **新开仓打 7 折，禁止激进加仓** | 轻度背离或市场拥挤度上升 |
| **`PASS`** | 1.00 | **允许按策略正常开仓与持仓** | 供需与盘面协调健康 |

## 四、 螺纹钢主力合约换月 (Rollover) 协议

上期所螺纹钢（RB）期货主力合约在一年内严格按 **01 $\to$ 05 $\to$ 10** 轮换：

1. **主力判定与换月触发条件**：
   - **条件 A (持仓量超越)**：次主力合约的持仓量（OI）连续 2 个交易日超过当前主力合约；
   - **条件 B (交割月强制换月门禁)**：若距离当前合约交割月份前一个自然月倒数第 15 个交易日尚未换月，触发强制移仓门禁（杜绝进入交割月流动性枯竭与高额保证金惩罚）。
2. **移仓执行与基差摩擦**：
   - 移仓日在次日开盘同时执行：按开盘价平掉旧合约，并在新合约按开盘价建立等同名义敞口（或等手数）；
   - 产生双倍手续费与滑点，并忠实记录跨期价差损益（Roll Spread PnL）。

## 五、 策略架构与信号规则基准

系统预置四大标准策略方案进行横向对照：

1. **基准策略 1 (Benchmark: Buy & Hold)**：在整个回测区间始终持有 1.0x 杠杆的螺纹主力多头，伴随主力换月，用于评估资产 Beta；
2. **对照策略 2 (Raw Fundamental Strategy)**：纯基本面裸奔策略。`Bullish` 即多，`Bearish` 即空，不经现货微观确认，无均线时机过滤，不经过风控防火墙，作为基准反面教材；
3. **Stage E 核心策略 (Quant Macro-Fundamental with Firewall)**：
   - **入场**：基本面方向明确 + 现货微观确认（`spot_confirmation == 'Confirmed'` 或基差处于有利分位）+ MA20 均线顺势动量突破；
   - **仓位预算**：依据置信度评分动态线性缩放（置信度 90 对应 1.0 满杠杆，置信度 50 对应 0.5 杠杆）；
   - **风控审查**：前置经过五重防火墙检验，受限时动态限仓，触发熔断时斩仓并冷却；
   - **退出**：基本面反转或转中性，或置信度衰减至 40 分以下，或防火墙强制止损。

## 六、 交易日志与格式规范

每一笔历史模拟交易必须生成格式化记录，严格对接 `交易/交易记录.csv`：

| 字段名 | 类型 | 说明 |
| :--- | :--- | :--- |
| `trade_id` | str | 交易唯一流水号 (如 `TRD_20240924_001`) |
| `prediction_id` | str | 对应的状态/预测快照 ID (如 `PRED_20240924_RB`) |
| `contract` | str | 具体成交合约 (如 `rb2501`) |
| `side` | str | 交易方向 (`BUY_OPEN`, `SELL_CLOSE`, `SELL_OPEN`, `BUY_CLOSE`) |
| `quantity` | int | 成交手数 |
| `entry_time` | str | 开仓时间 (YYYY-MM-DD 09:00:00) |
| `entry_price` | float | 实际成交开仓价 (含滑点) |
| `exit_time` | str | 平仓时间 (YYYY-MM-DD 09:00:00) |
| `exit_price` | float | 实际成交平仓价 (含滑点) |
| `fees` | float | 累计手续费与滑点成本 (元) |
| `risk_plan` | str | 开仓时的风控预案 (如 `FIREWALL_MA20_STOP_1.5%`) |
| `execution_deviation` | float | 执行滑点偏差 |
| `note` | str | 交易触发原因或强平说明 |
