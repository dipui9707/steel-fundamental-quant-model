# A05.6 成本推升参与候选与追高检验

版本：`cost-push-0.3-candidate`，2026-09-23。在 framework-0.3-candidate 与 cost-push-0.2 基础上升级。针对“突破追高接盘、回调过早扫损、错失后续主升浪”的结构性缺陷，实现双轨入场（启动期突破轻仓底仓 + MA20回踩企稳主攻仓）、趋势生命线止损与主升浪二次追击状态机。A09 登记 ARCH-H-026至030，均为待验证、未进入正式模型。

## 目的与边界

原策略将低利润、低基本面置信度、基差偏弱及价格离均线偏远一起用于限制入场，可能漏掉原料先涨、成材随后跟涨的阶段。0.2版本初步接入后，发现突破追高常买在第一波尖峰，且正常回调打掉过紧止损后，因清空状态而彻底踏空后续大主升浪。0.3版本解耦“启动期突破”与“高位透支”，引入“MA20回踩企稳买点”与“平仓后主升浪二次追击状态机”，既防直拉单边踏空，又防天花板接盘。

只在**实际空仓且原策略输出 FLAT** 时尝试新路径。原策略已有多空仓位保留原管理规则；不叠加两个头寸，不接管旧仓、不直接反手。成本仓成交后按自身理由管理，直到退出；不会因原策略后来转为多头而自动扩大为原策略仓位。原策略默认入口不变，新比较入口显式启用成本路径。

当前范围是“原料相对推涨 + 成材价格确认”。没有带发布时间的宏观事件证据，因此**不实现单凭宏观分高就做多**，也不将原料价格脉冲解释成政策因果。亏损→铁水减产的原 COST 物理账本保持原义，本模块不将其冒充为成本传导确认。

## 状态和条件

|状态|条件|行动|
|---|---|---|
|OBSERVE|原料相对成材5日涨幅差>1.5%，且原料领先标签/挤仓标志/任一挤仓指数≥2|等待成材确认，不因标签直接开仓|
|EARLY_BREAKOUT (PILOT)|收盘突破前20日高点，**且距MA20在启动区（偏离<=3.5%且<=2.2 ATR）**；原料推涨成立，成材上涨|建立轻仓防踏空底仓（10%资金使用率）；防一去不回头极强单边|
|OVERBOUGHT_HOLD|突破但距MA20超过3.5%或超过2.2 ATR|判定短线透支，一票否决追高，建立setup等待回踩|
|FIRST_PULLBACK|前期突破后回踩触及突破位上方0.5ATR或MA20均线带，守住MA20生命线且今日收阳企稳|建立/追加主攻仓（20%资金使用率），低成本吸筹迎接主升浪|
|SECOND_LEG_RE_ENTRY|平仓后15日内，原料推升大背景未死，成材洗盘企稳重上MA20并突破前5日高点|激活主升浪二次追击（20%资金使用率），彻底攻克洗出即踏空痛点|
|TRANSMISSION_CONFIRMED|入场后现货与出库确认，利润已知且>100元/吨|最高升至25%资金使用率|
|EXIT|收盘跌破保护位、数据未知、现货出库明显转弱、原料推升消失且成材不涨、或超时|收盘生成平仓，次日开盘执行；平仓后保留15日二次追击观察期|

入场附加约束：

- 突破追高门禁：收盘距MA20偏离必须<=3.5%且<=2.2 ATR。超过则强制转入等待回踩。
- 止损生命线：初始保护位与持有保护位锚定 max(突破位−ATR20，MA20×0.985)；保护位只能上移，接受原MA60、极端波动和数据停机风控。
- 杭州现货5日跌幅不得超过1%；最近5日平均出库/此前5日平均出库不得低于0.70。任一恶化即阻止入场/触发退出。
- 低利润与利润未知保留原数值含义，只有确认且利润>100元才允许提至25%满仓确认比例。

## 风险预算与权限

以乐观情形**保证金资金使用率50%**为满仓基准：

|档位|占满仓基准的比例|默认保证金资金使用率|10%保证金率下名义杠杆|
|---|---:|---:|---:|
|系统乐观满仓上限|100%|50%|5倍|
|启动期突破试单，或低利润/利润未知|20%|10%|1倍|
|MA20回踩企稳主攻仓 / 二次追击主攻仓|40%|20%|2倍|
|传导确认当日且利润>100元/吨|50%|25%|2.5倍|

20%/50%的分档是本轮实施设定，未按历史收益优化。本次成本路径最高使用25%，系统50%上限作为分档基准；没有增加自动升级到50%的新入场或加仓条件。若比较入口将满仓上限调低，各档按比例调低；拒绝高于50%的配置。保证金率变化时，以实际配置的保证金率换算手数，而非固定1倍/2.5倍杠杆。

目标手数 = floor(权益×该档资金使用率÷每手保证金)，然后接受防火墙降档、高波动与账户上限、整数手数和只平不增约束。例如中度背离容量为50%时，试单实际目标约5%，确认仓约12.5%；高波动的2倍名义杠杆上限仍可能限制确认仓。

损失距离仍为 max(2×ATR20、收盘到保护位距离、价格1.5%)，保留“目标名义敞口/权益×距离比例”的估计损失记录；它不是固定预算，也不是最大亏损保证。必要距离缺失时不下发仓位。调用方若另行显式指定更小的账户损失预算，仍取两者交集，默认比较入口没有该附加预算。

新路径不套用旧置信度、强度或Carry乘数；这些仍约束原策略。未确认时禁止持续加仓；确认当日满足利润条件才允许一次提高目标，随后不因每日价格/权益变化自动加仓。入场条件、3ATR追高上限、止损、确认超时与冷却均保持0.1版本不变。

标准防火墙只有一处新增语义：**基本面看空、价格向上背离时，成本顺势多头的中度背离判为限仓警戒**。旧策略仍只平；严重背离、价格硬止损、极端反向脉冲、数据停机及冷却保留。判定发生在防火墙内部，不能把已经输出的 RESTRICT_CLOSE_ONLY 改写为开仓许可。独立共同价格风控对照不使用基本面背离信息。

信号不等于成交。路由器接收下一日实际持仓回报之后才建立入场上下文；被风控阻止或整数手数为零不会启动持仓计时。换月继续同一成本持仓段，平仓后再入场才是下一段。

这是日线收盘判断。突破止损下一日才能执行，跳空、涨跌停和连续合约切换可使实际损失超过预算；10%/25%资金使用率不等于10%/25%的最大亏损。

## 如何继续测试

在项目目录运行：

```bash
.venv/bin/python scripts/run_cost_push_comparison.py --start 2021-01-04
```

默认：保留Carry的原策略与新增成本路径成对比较，最高保证金利用率50%，标准完整防火墙。默认不运行既有12组参数比较，也不调参。每次生成新的独立实验目录，不覆盖旧结果。

要与上一轮“共同价格风控”的实验口径对应，运行：

```bash
.venv/bin/python scripts/run_cost_push_comparison.py --start 2021-01-04 --risk-mode price-only
```

可加 `--end YYYY-MM-DD` 限定区间，`--without-carry` 两组同时关闭Carry。比较时始终使用**同次实验的 BASELINE 与 COST_PUSH**，不能把不同风控模式的旧报告直接当增量收益。

|产物|检查内容|
|---|---|
|manifest.json / source_snapshot / artifact_hashes.json|参数、输入、代码冻结与口径限制|
|comparison.csv / year_blocks.csv|全账户收益、回撤、杠杆及分年结果|
|COST_PUSH_decisions.csv / parquet|每个新路径门槛、原策略拒绝理由、入场驱动、阶段、计划/最终资金使用率、估计距离损失、保护位、最后新增证据日期、风控结果、零手数、退出理由|
|cost_episodes.csv|实际成交持仓段，突破/回踩、距MA与ATR距离、是否超过旧2.5%门槛、入场手数、计划/实际使用率、持有期、净账户损益、最差/最好日终浮动、同期原策略收益、退出原因|
|chasing_summary.json|新增成交/已平仓/亏损段数，超过旧距离门槛的段数和损益，超时及破位退出数；零样本损益为空值|

追高不只看胜率：逐段检查超过旧距离门槛的亏损、假突破、确认超时、全账户最大回撤是否恶化，再看新增参与收益能否覆盖这些损失。`worst_marked_return_pct` 是相对该段入场前权益的最差日终浮动，包含费用和结算估值，**不是盘中价格MAE**。未平仓段不计胜负；换月与减仓不重复计算为独立交易。两策略后续持仓路径会改变，同期收益差不是严格因果贡献。

本版本只完成工程验证。短区间可能没有新增交易，不能据此判断追高风险没有增加。扩大区间也属于已使用历史上的探索，不能冒充独立样本外。后续若修改门槛，必须登记新候选版本并保留本版本结果。

## 实现与输入

- `stage_e/cost_push_router.py`：过去数据特征、候选状态机、实际成交生命周期。
- `stage_e/signal_generator.py`、`backtest_engine.py`：可选信号字段、成交反馈和逐日审计。
- `stage_e/position_sizer.py`、`risk_filter.py`、`stage_c/risk_firewall.py`：小预算约束和策略驱动的背离处理；默认旧路径保留。
- `stage_e/cost_push_diagnostics.py`、`scripts/run_cost_push_comparison.py`：同条件比较和实际持仓段归因。
- `tests/test_cost_push_router.py`：未来数据截断不变性、缺数/追高拒绝、低置信试仓、确认、超时、冷却、硬风控、仓位约束、T+1成交和归因等反例。

数据来源：现有 `数据/加工/阶段B_特征宽表.parquet` 与 `数据/原始/期货合约全量日线/standardized/rb_daily.parquet`，2026-09-23本地读取。本轮无Wind或其他外部取数，不改原始数据、历史行情、PIT库或真实交易台账。具体字段口径仍受既有数据地图与采集回执约束。
