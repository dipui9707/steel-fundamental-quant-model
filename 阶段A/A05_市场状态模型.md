# A05 市场状态模型

状态：组合与输出契约草案｜依据：手册第7—11节

## 判断步骤

1. 固定判断时点、数据批次和规则版本，按A04构造当时信息集。
2. 判断宏观或极端情绪是否可能覆盖产业逻辑。
3. 拆解总资源、品种分配、螺纹供需及库存变化来源。
4. 分别记录现货确认、情绪反馈及价格结构。
5. 明示背离，按A06记录可信度及限制。
6. 保存方向、强度、持续性、生命周期，并写出可证伪条件。

## 输出字典

| 字段 | 允许值或内容 |
|---|---|
| as_of | 带时区的判断时点 |
| model_version / snapshot_id | 模型版本和快照唯一标识 |
| Macro Regime | 产业主导 / 宏观覆盖 / 混合 / Unknown |
| Fundamental Direction | Bullish / Bearish / Neutral / Unknown |
| Fundamental Strength | High / Medium / Low / Unknown |
| Spot Confirmation | Confirmed / Mixed / Rejected / Unknown |
| Sentiment State | 启动 / 强化 / 拥挤 / 钝化 / 反转 / 平稳 / Unknown |
| Market Structure | Bull Trend / Bear Trend / Range / Unknown |
| Divergence State | None / 产业价格背离 / 产业现货背离 / 多重背离 / Unknown |
| Model Confidence | High / Medium / Low / Unknown |
| Persistence | High / Medium / Low / Unknown；附预期交易日范围 |
| Lifecycle | 孕育 / 启动 / 强化 / 成熟 / 衰减 / 反转 / Unknown |
| evidence_ids / risks / invalidation | 数据版本引用、风险及失效条件 |

## 场景研究表

| 产业 | 现货 | 价格 | 需记录的状态 |
|---|---|---|---|
| 偏多 | 确认 | 上升趋势 | 候选一致状态，仍检查强度、持续性和外部覆盖 |
| 偏多 | 否认 | 下降趋势 | 多重背离，追查时滞、预期变化及宏观/资金覆盖 |
| 偏空 | 确认偏空 | 下降趋势 | 候选一致状态，仍检查是否充分定价 |
| 方向冲突 | 混合 | 震荡 | 证据充分时可中性；证据不足则Unknown |
| 缺失 | 任意 | 任意 | 产业方向Unknown，其他已知模块独立保留 |

方向、强度、持续性、生命周期是不同轴，不相互自动推导。当前不设置固定总分或权重，不生成仓位。状态门槛及生命周期转换条件需通过A09验证后确定。
