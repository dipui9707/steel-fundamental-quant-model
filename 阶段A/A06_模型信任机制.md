# A06 模型信任机制

状态：2026-09-20人工审查候选框架，等级阈值待验证｜依据：手册第4.6、8—9、17节

## 每次判断需回答

| 维度 | 证据 | 需记录的限制 |
|---|---|---|
| 数据质量 | 来源、历史版本、发布时间、样本变化 | 缺失、过期、重复、修订、不可比 |
| 内部一致性 | 总资源、分配、需求和库存的链条 | 同一派生数据的重复计证 |
| 现货确认 | 价格、成交与区域差 | 成交或库存的局部样本偏差 |
| 价格确认 | 趋势及预期响应 | 价格提前反映、产业逻辑已定价 |
| 外部覆盖 | 有时间戳的宏观/政策事件 | 事件是否足以解释价格变化 |
| 情绪覆盖 | 持仓、广度、拥挤及信息响应 | 逼仓/恐慌解释需证据，不凭价格猜测 |
| 背离持续 | 起始快照、累计观察周期、反例 | 不把重复周数据算成多个独立证据 |

## 处理顺序

关键输入缺失或可用时间不明时，相关模块输出Unknown，并列出具体缺项。已有判断但出现现货否认、价格背离或宏观覆盖证据时，记录降低信任的理由；持续背离不能提升信任。所谓“持续”的周期、数据过期阈值及降级幅度尚待校准。

人工草案可使用High/Medium/Low，但每次必须附证据和“人工评估”标签，不能伪装为已验证计算结果。缺乏评估依据则用Unknown。恢复信任需要新发布的确认性证据和可复现的规则，不能仅因为价格回到预期方向。

## 微观结构与信息降级契约

本节取代 V0.2 的“2σ即机构拥挤”“等待两日流出后激活做空”等未验证规则。研究层只输出风险、证据和可信度，不生成开仓/加仓/做空扳机。详细边界见 [A05.2](A05.2_黑色五品种期货资金投机度与量化对比规范.md)。

1. **披露范围**：TNB是前20披露结构，不是全市场净多头或最终客户方向。榜单截断、同日OI、合约和来源不匹配时指标Unknown；CS与TNB在原公式下重复，不能作为两个确认票。会员标签未经客户级证据验证，不得判“产业疯狂卖保”。
2. **异常尺度**：经验分位[0,1]与Z分数分开。60日/2σ等门槛先登记为候选，并验证换月、季节和交割效应。异常只提示需复查，不直接证明逼仓、反转或预测概率。
3. **价格/产业冲突**：持续背离记录价格、现货与实物证据各自版本，降低对原解释的依赖或输出Unknown；不能仅因价格回归就提高模型可信度。相同周报沿用不得反复计证。
4. **发布与质量事件驱动**：周报未到下次应发布时点可仍有效；真正延迟、缺项、口径冲突或来源不可核实时降级。不能按周一/周五或统一48小时机械切换；新数据实际可得且通过校验后才重新评估。市场量价仓描述仍可保留，但不能补齐缺失的产业判断。
5. **分开不确定性**：data_quality、fundamental_trust、microstructure_quality与scenario_score_weight各有口径。启用候选软权重须标UNCALIBRATED；未校准则不输出发生概率。规则未定或证据不够时写Unknown，不能以人为分数伪装胜率。
