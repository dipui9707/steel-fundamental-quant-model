# A02.1 总钢材资源池

状态：阶段 A 设计审定稿；无历史因果验证、无可交易参数｜设计日期：2026-09-20（Asia/Shanghai）｜任务：T002 设计部分、T-ARCH-003

本页回答“在工艺、设备、原料、订单和政策约束下，有多少资源能进入成材生产”。先识别总量，再由 [A02.2](A02.2_卷螺品种分配.md) 解释品种分配。本次增加计量边界、可证伪机制与研究契约；来源、合成反例和限制见 [审查记录](../../研究/架构审查/03_产业因果与反例审定.md)。

## 1. 资源池分层：数量不能跨层相加

| 层次 | 定义与允许用途 | 禁止的替代或加总 |
|---|---|---|
| 高炉铁水 | 高炉产出；样本铁水和全国生铁分别保留范围，是后续炼钢投入和矿焦消耗条件变量 | 不是全国粗钢或螺纹供应；与粗钢相加重复计入上游投入 |
| 粗钢 | 完成冶炼而未经塑性加工的钢；按统一制度区分 BOF、EAF 和其他路径 | 全国粗钢已覆盖其统计范围内各工艺，不能再叠加电炉粗钢；全国月度值不能减样本周度值 |
| 钢坯/板坯 | 从粗钢流向轧制的半成品，有库存和跨厂转移 | 外购坯再轧不是新增粗钢；样本内调坯不能同时计入两厂的新增资源 |
| 钢材 | 明确产品形态、加工层次和样本的产出 | 热卷再加工为冷轧会跨工序统计；未剔重钢材产量不能当一次成材净资源 |
| 五大材 | 通常指螺纹、线材、热卷、冷轧、中厚板的特定调查集合，以供应商方法为准 | 不是全钢材或总铁水的质量守恒出口；热卷与冷轧存在上下游关系，合计只作约定样本指标 |

国家统计局工业统计司区分粗钢和生铁定义，统计范围均为规模以上工业调查单位；这不证明商业铁水系列与其同口径。[国家统计局答复，2023-05-08](https://www.stats.gov.cn/hd/lyzx/zxgk/202305/t20230531_1940293.html)。历史年鉴出现扣除重复钢材的注释，支持核查加工重复的必要性，不能提供当今样本剔重系数。[2010 年统计年鉴，表 14-23 注 6](https://www.stats.gov.cn/sj/ndsj/2010/html/N1423C.HTM)。

同范围、同期间、同一粗钢统计边界且工艺互斥时，才可写：

`Q_crude = Q_BOF + Q_EAF + Q_other`。

“铁水 + 废钢 = 粗钢”只是投入路径的简写，不是可直接计算的等式。需逐厂统一质量口径、配料和收得率，核算非铁杂质去除、合金加入、损耗、回炉料和在制品变化。没有这些资料时，分别展示铁水、电炉等代理，不制造一个总资源吨数。

## 2. 工艺链与废钢弹性

```mermaid
flowchart TD
  O[铁矿品质与到厂资源] --> BF[高炉铁水]
  COAL[配煤与焦化] --> COKE[焦炭供给与质量]
  COKE --> BF
  BF --> BOF[转炉炼钢]
  SCRAP[废钢到货 质量与价格] --> BOF
  SCRAP --> EAF[电炉炼钢]
  POWER[电价 供电与其他投入] --> EAF
  METAL[经核实的铁水 DRI等配料] --> EAF
  BOF --> CAST[分钢种连铸 板坯或方坯]
  EAF --> CAST
  CAST --> BILLET[坯库存 外购外售与调坯]
  BILLET --> ROLL[设备与订单约束下的轧制]
  ROLL --> PRODUCT[一次成材与后续加工分开计量]
  PROFIT[现金贡献与订单] --> BF
  PROFIT --> EAF
  PROFIT --> ROLL
  RULE[政策 检修 能源与资金约束] --> BF
  RULE --> EAF
  RULE --> ROLL
```

箭头是带条件的路径，不给稳定系数。BF-BOF 和 EAF 均可使用废钢，EAF 还可能使用 DRI 或铁水，不能把废钢增量全部解释成短流程增产。[worldsteel：What is steel?](https://worldsteel.org/about-steel/what-is-steel/)

| 环节 | 废钢作用 | 约束与观测边界 |
|---|---|---|
| BF/BOF | 研究转炉废钢配比对粗钢产出、铁水单耗和成本的作用；可补充金属料或替代部分铁水 | 热平衡、废钢品位、转炉/精炼能力及配比须核实；铁废差（铁水成本 - 废钢价格）>150~200元时转炉自发提高废钢比 |
| EAF | 供电、原料、人工、订单和设备有余量时，经济性改善可能增加开炉时数或产量 | 电价时段（平谷电）、金属收得率、到货质量共同约束；平电成本构成反弹压力位，谷电成本构成绝对支撑下轨 |
| 区域工艺非对称性 | 华东长流程主导 vs 西南/华南短流程密集 | 华东长流程占绝对垄断，独立电炉前几年已基本淘汰出清；西南水电丰水期电炉密集形成价格洼地（蓉杭深贴水）；华南制造业废钢充沛、电炉受夏季错峰限电强调节（穗杭宽幅震荡） |
| 废钢供需到耗 | 价格与地区价差影响回收流向；到耗剪刀差直接驱动钢厂调价 | 320家样本到货与周度日耗构成核心供需剪刀差；到货<日耗钢厂提涨吸货，到货>日耗钢厂压车降价 |
| 跨工艺竞争 | BOF 与 EAF 争夺适用品级废钢；长流程铁水成本压制废钢上行天花板 | 等级、税票、运费、地区、配料比例综合衡量，铁水成本过低时废钢需求承压 |

外购焦炭成本已包含上游焦煤影响，不可再完整计入同一份焦煤成本。自有焦化可拆配煤、焦化现金支出和副产品收益，但与外购焦炭法须二选一或按实际占比分段。动力煤价不能自动替代焦煤、喷吹煤或实际电价。AISI 工艺说明支持焦煤—焦炭—高炉与不同炼钢路径的区分。[AISI：Steel Production](https://www.steel.org/steel-technology/steel-production/)

### 2.1 现货微观结构：中天贸易锚与三类 CTD 交割锚双轨制

在现货流通与期货交割实务中，必须严格区分主流现货标的与期货交割锚定物：

1. **主流期现贸易流动性标的（中天螺纹，`S_HZ_ZT`）**：
   - 华东乃至全国流通规模最大、期现贸易量最大的现货标的；
   - 包含稳定的**品牌与流动性溢价**（中天 - 三类，常态在 60~90 元/吨）；
   - 期现商买货抛盘、现货点价与库存质押均以中天为核心商业贸易锚。
2. **最便宜可交割品 CTD（三类螺纹，`S_HZ_TIER3`）**：
   - 期货盘面具有空头交割选择权，交割月价格天然向全市场成本最低、价格最便宜的三类螺纹收敛；
   - **交割收敛基差**：$\text{Basis}_{\text{CTD}} = \text{三类螺纹} - \text{期货收盘价}$，临近交割月必然向 0 收敛；
   - **商业贸易基差**：$\text{Basis}_{\text{Trade}} = \text{中天螺纹} - \text{期货收盘价} = \text{Basis}_{\text{CTD}} + \text{品牌溢价}$；
   - **严禁将中天基差直接当作交割无风险套利基差**，避免“虚假深贴水”做多陷阱。

### 2.2 惠龙港内河水运物流边界与期现持有成本（Cost of Carry）模型

现货物流与金融交割必须计入真实无套利物理边界与时间价值衰减：

1. **惠龙港至杭州内河水运无套利边界**：
   - 惠龙港作为江苏江海转运最大码头，到杭州主要走京杭大运河/江南运河内河散货驳船水运；
   - **综合物流加总成本**（水运驳船运费 + 码头吊装 + 入库仓储等杂费）约为 **50 元/吨**；
   - **水运净套利利润**：$\text{HLG\_NET\_ARBITRAGE} = (\text{杭州螺纹} - \text{惠龙港螺纹}) - 50.0$；
   - 当价差 $> 50$ 元/吨时，存在水运调拨盈利空间；当价差 $> 100$ 元/吨时，江船大量涌入杭州，预警本地累库抛压。
2. **期现业务与交割仓单资金持有成本模型（纯资金利息法）**：
   - 现货商买现货、注册仓单并在期货卖出锁定利润的“正套业务（Cash and Carry）”，核心考量**资金占用与利息成本**；
   - **资金利息率基准**：按产业贸易商授信与资金借贷成本基准 **6% 年化** 核算；
   - **持有至交割日资金利息成本**（按实战规则：此项只计算资金利息，仓储与其他杂费不计入）：
     $$\text{Full\_Carry\_Cost} = \text{Spot}_{\text{CTD}} \times \left(\frac{6\%}{365}\right) \times \Delta t_{\text{delivery}}$$
   - **无风险期现正套净利润（Net Arbitrage Margin）**：
     $$\text{Net\_Cash\_Carry\_Margin} = \text{Futures\_Price} - \text{Spot}_{\text{CTD}} - \text{Full\_Carry\_Cost}$$
   - **实战启示**：
     * 远月合约由于剩余天数长（如 100 天以上），资金利息成本高达 50 元/吨以上，盘面看似升水 10~20 元实则扣减利息后净套利为负（$-40$ 元左右），无法吸引正套资金开仓；
     * 临近交割月 1~2 个月时，资金利息成本随时间快速衰减至 20 元以下，一旦盘面升水覆盖资金成本（$\text{Net\_Margin} > 0$），期现套利资金开始规模入场，强力促发期现收敛。

3. **期货期限结构、跨期月间价差与盘面虚拟钢厂毛利传导**：
   - **跨期月间价差（Calendar Spreads）与库存蓄水池的相互验证**：
     * **Contango（正向市场，价差 $< 0$）**：近月贴水远月，直接映射近端现实高库存、出库低迷与现货端累库承压。此时套利商易在近月买入仓单并抛空远月锁定无风险利差，反向加剧近端抛压；
     * **Backwardation（反向市场，价差 $> 0$）**：近月升水远月，映射近端低库存、出库旺盛与现货端阶段性紧俏。多头驱动集中于近月交割逼仓，去库弹性大幅放大；
     * **展期收益率（Roll Yield）**：以年化展期收益率量化期限结构曲率与升贴水斜率。
   - **盘面虚拟钢厂毛利（Virtual Steel Mill Margin）与原料负反馈边界**：
     * **计算式**：$\text{VIRTUAL\_STEEL\_MARGIN} = RB - 1.6 \times I - 0.5 \times J$（元/吨）；
     * **扩张正反馈区间（$> 200$ 元/吨）**：高炉复产驱动充沛，铁水产量回升，带动铁矿双焦补库，形成“成材带原料”上涨循环；
     * **深度亏损负反馈区间（$< -100$ 元/吨）**：盘面毛利击穿长流程现金成本并持续 2 周以上时，亏损倒逼钢厂自主检修减产，铁水产量见顶回落，引发原料端（尤其是高估值铁矿）踩踏式补跌，形成“成材倒逼原料负反馈”。



## 3. 利润分层与停产条件


| 字段 | 定义 | 判断边界 |
|---|---|---|
| 账面利润 | 含存货计价、折旧等会计口径，归属期与披露时间分开 | 经营结果，不直接给出当下增减产边界 |
| 即期重置成本利润 | 同地区、税、质量、运费、产出率和加工层次下，现货售价减当期重置成本 | 成本方向代理，不是已实现利润或逐厂现金贡献 |
| 决策期现金贡献 | 决策期可实现销售净收入减继续生产新增且可避免的现金支出 | 与停复产成本、合同、流动性和设备约束共同研究生产选择 |
| 盘面虚拟利润 | 对齐月份、吨口径与配方的 RB/HC/I/J 等期货组合 | 价格预期和价差压力代理，不是现金停产线或公允价值 |

研究式为 `CM = P_net_realizable − C_avoidable_cash`，按同一吨合格成材或铁水口径计算，注明决策期；沉没支出、固定支出和边际支出分开。回款时点、库存机会成本、保供合同另列。数据不足为 `cash_margin = Unknown`。

继续生产与停产再复产应在同一决策期比较预计净现金流，加入检修、复产成本和技术约束。CM 为负是压力候选，既不必然即刻停炉，也不证明继续生产合理；CM 为正也不排除行政限产、故障或断供。“为了授信坚持生产”需企业级证据，本稿不写成已核实历史事实。

## 5. 库存恒等式与表需代理

先定义边界 Ω：规格、工厂集合、仓库集合、地区、统计起止时刻和覆盖的流转节点。厂库和社库须不重复且可对接，不能默认不同调查样本天然闭合。

同边界下，P 为该产品产出；N 为非终端用途跨边界净流入（进口、出口、跨区流转按方向计）；U 为从边界流向下游使用的量；L 为损耗；ε 为净增加库存的统计/边界误差：

`ΔI = P + N − U − L + ε`。

常见简化表需为 `D_app = P − ΔI`，所以：

`D_app = U + L − N − ε`。

这是产销存余额代理。U 还可能含下游再加工投料、未统计下游库存增加，不等于工地真实消耗。只有额外核实净流入、损耗、统计差和下游库存，才可能更接近终端需求。

- P 与 I 的期间、产品和样本必须一致，期初期末均保留当时版本。
- 供应商如含进出口或扩样调整，按其方法核实，不能默认简化式。
- P、ΔI、D_app 及其变换共享 `evidence_group_id`，不作为三份独立证据。
- `P − ΔI − D_app` 接近零只验证算术，不证明需求测量准确。
- 跨周、换样、单位、加工层次或发布时间未解决时标记 `Unknown` / `scope_mismatch`。
