# A02.2 卷螺品种分配

状态：阶段 A 设计审定稿；无历史因果验证、无可交易参数｜设计日期：2026-09-20（Asia/Shanghai）｜任务：T-ARCH-003

本页回答“螺纹供给变化来自总量、工艺差异还是重新分配”。总量依照 [A02.1](A02.1_总钢材资源池.md)；来源与反例见 [审查记录](../../研究/架构审查/03_产业因果与反例审定.md)。

## 1. 条件因果链

`可实现订单与相对现金贡献 → 已确认可调度的炼钢/连铸/轧制路径 → 品种配置 → 分品种产量 → 库存及现货 → 下一轮订单和利润`。

“热卷利润改善 → 螺纹供应下降”要求共享约束资源、可调路径、订单、可接受切换成本以及其他供给不抵消等条件。全国热卷增产和螺纹减产的相关性，不能证明同一钢厂铁水转移。

## 2. 可切换产能不是所有产能

炼钢、板坯/方坯连铸、轧制能力分别建表。拥有热卷轧线不等于同一轧线能够改轧螺纹；钢种、规格、连铸断面、加热炉、精轧、冷却和订单认证都可能约束。可调度常发生在钢水分配和不同既有生产线排产，不能写成所有轧机随利润差即时转产。

设备商分别设计热带与棒线材机组，POSCO 区分板坯、方坯及下游加工。资料支持路径不同，不提供中国钢厂可切换比例或时长。[SMS 热带轧机](https://www.sms-group.com/plants/hot-strip-mill-for-steel)、[POSCO 工艺说明](https://newsroom.posco.com/en/steel-made/)。

逐厂路径表至少含：`plant_id`、`route_id`、钢水来源、连铸类型、轧线/规格、有效产能、检修区间、订单锁定量、`switchable_to`、切换成本/用时证据、`available_date`。无证据的可切换性为 `Unknown`；没有微观表，只做宏观描述。

对可核实路径 r 和品种 p，研究约束为：

`0 ≤ q[r,p] ≤ K[r,p,t]`；不存在的路径固定为 0，未知能力不填数。

共享资源时，`Σ_p q[r,p] / yield[r,p] ≤ M[r,t]`，其中 q 为合格成材吨、M 为同路径可用坯/钢水吨，yield 为同边界收得率。还受订单、能源、物流、检修约束；全国铁水不能代入单厂 M。此约束用于可行性检查，未求解利润最优配置，不输出产量预测。

## 3. 总量、结构、工艺与坯流转拆分

优先使用互斥路线：长流程一体化成材、EAF 成材、外购坯调坯轧制、必要的其他路径；同一吨一次成材只计一次。外购坯在粗钢和轧制层分别记流向，不是两个新增资源。

固定样本 Ω、同期间和同一加工层次下，Q 为全部一次成材产量，Q_R 为螺纹、Q_H 为热卷，其他品种不得遗漏：

` s_R = Q_R / Q `；` s_H = Q_H / Q `；` s_R + s_H + s_other = 1 `；要求 Q > 0。

相邻有效期间取 `s̄_R=(s_R,t+s_R,t−1)/2`、`Q̄=(Q_t+Q_t−1)/2`，精确算术分解为：

`ΔQ_R = s̄_R × ΔQ + Q̄ × Δs_R`。

总量项与结构项是恒等式分解，不是因果贡献估计。结构项可能来自钢厂权重、检修或产品退出，不能直接命名热卷挤占量。

只有 Q_H 与 Q_R 时允许 `pair_share_R = Q_R / (Q_R + Q_H)`，名称必须是卷螺二品种占比，不能解释为全国铁水占比。五大材多工序合计不能代替 Q。

分工艺时在互斥路线内部计算再汇总 `ΔQ_R = Σ_r ΔQ_R,r`。EAF 已在 Q 内时，不在分解外再加电炉贡献。坯库存释放、净外购坯和成材率变化可以解释路径变化，未经观测不能把各机制再分别计成额外贡献。

## 4. 同口径相对利润与订单

`ΔCM_HR = CM_H − CM_R` 比较同厂、同决策期、同税/运费、按可替代共享资源折算的可实现现金贡献。每吨成材利润不一定代表每吨钢水或瓶颈产能小时的收益；需校准收得率和工序约束。

全国现货利润、期货 `HC − RB`、出口报价分别作代理，不能回填逐厂现金利润。合约月份、质量、交货地、仓储、信用和出口净回款差异须保留。出口订单 PMI 是扩散指数，不能换算热卷吨数；全钢材出口不能全归热卷。

订单区分报价、意向、已签、排产、发运、报关、下游消耗，各阶段保留取消/延期与实际可用时间。不能将后来海关出口值作为此前某日已知订单。
